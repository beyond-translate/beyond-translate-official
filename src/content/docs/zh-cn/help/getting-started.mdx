## 第一次划词翻译

在任意网页上选中一段文字，选区旁会出现 Beyond Translate 的图标。点击图标，译文面板会在原位展开。

- 选中单个单词时，如果开启了「释义模式」，面板会显示音标、词性、义项、例句与词源。
- 原文与译文都可以朗读和复制。
- 面板底部的快捷搜索可以用 Google、Forvo、剑桥词典、Dictionary.com 或维基词典在新标签页查这段文字；在设置页「划词 › 快捷搜索」里启用、排序或新建自定义项。

触发方式可以在设置页「划词」里改为「自动弹出」或「禁用」。选中图标的位置可以跟随选区终点，也可以固定在行首、行尾、上方或下方。

## 整页翻译

点击浏览器工具栏里的 Beyond Translate 图标，打开工具栏面板。选择翻译模式，然后开始翻译：

- **双语对照**：在每个段落之后追加译文，保留原文。
- **仅译文**：把译文放在原文的位置；链接、加粗等行内元素与页面交互原样保留。

两种模式都能随时点「显示原文」还原。页面在译文出现后自行更新的内容不会被旧译文覆盖，会按新文字重新翻译。

整页翻译分「全文」与「主内容区」两种作用域。用 Web Components 构建的页面同样可以翻译，扩展会进入 open 与 closed 的 Shadow Root。

## 工具栏面板

工具栏面板针对当前标签页展示站点规则，并让你选择作用域、目标语言、翻译服务、提示词、自动翻译与自动存档。底部可以直接进入设置；「更多」菜单里有翻译服务、提示词、站点规则、生词本、译文存档与备份还原。

## 设置页

设置页按分区组织全部功能：

- **通用**：目标语言、界面语言、主题与译文字体。
- **划词**：触发方式、图标位置、面板尺寸、释义模式与快捷搜索。
- **整页**：默认翻译模式、作用域、翻译进度。
- **悬浮球**与**预翻译**：两个可选的快捷入口。
- **翻译服务**：模型供应商与机器翻译服务。
- **提示词**、**站点规则**、**生词本**、**译文存档**、**备份还原**与**许可**。

所有改动即时保存。

## 悬浮球与预翻译

悬浮球是页面边缘的整页翻译快捷入口，默认关闭。开启后点一下即可按当前站点规则整页翻译，再点一下还原；可以拖动，位置全站共用。

预翻译也是可选项，默认关闭。它会在你靠近悬浮球或打开工具栏面板时，先在后台取回第一屏译文并放进缓存；随后点击翻译，第一屏会直接出现。
