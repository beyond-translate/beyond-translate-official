本页说明 Beyond Translate 如何处理数据，以及本站官网自己的做法。

## 密钥与凭据

API Key、云厂商 Access Key、网盘授权、GitHub 令牌、WebDAV 密码与数据密钥只保存在本机的扩展存储中。内容脚本拿不到这些凭据；扩展的设置页与测试结果也不会把凭据写进日志或错误信息。

## 翻译请求

翻译时，所选文字会发给当前选择的翻译服务：

- 使用 Google 翻译或 Bing 翻译时，文字发给对应服务的免费端点。
- 使用 Google Cloud Translation、Azure Translator、阿里云机器翻译或火山引擎机器翻译时，文字发往你自己的云厂商账号。
- 开启兜底翻译后，模型仍失败的整页段落会再发给所选的兜底机器翻译服务。

Firefox 安装时的数据外发声明对应该行为。扩展不会记录来源页面。

## 缓存、生词本与译文存档

- 翻译缓存只存在本机，用于复用已成功的译文；不入备份、不同步，也不记录来源页面。
- 生词本保存你主动加入的词句，不记录来源页面。
- 译文存档保存整页译文，只存在本机；是否存档由你手动操作或站点规则决定。

## 备份与同步

扩展配置、生词本与译文存档可以打包成加密 `.zip` 备份，也可以手动上传到 Gist 或 Dropbox、Google Drive、OneDrive、WebDAV。备份与同步文件始终用数据密钥加密；上传、下载、历史与恢复只在用户手动操作时进行。

同步凭据只保存在本机，不进入备份。Gist 同步只含扩展配置与生词本；网盘同步包含同一个加密备份包。

## 站点访问权限

扩展在安装时一次授予主机权限（`<all_urls>`）。用途是：划词与整页翻译需要在任意网站上运行；翻译请求需要访问用户自选的模型端点（包括本地服务与自定义 Base URL）与同步后端。

收回站点访问后，翻译会失败；设置页顶部与测试结果里会出现「授权」按钮，点击即可重新允许。

## 许可

许可状态、激活邮箱、许可凭证与刷新密钥只存本机，不进入备份与同步。

激活时，扩展会把邮箱与设备名发给许可服务；打开许可页时最多每天检查一次，不做后台轮询。未激活时不发起任何许可请求。停用本设备会清除本机的凭证与邮箱，并释放一个设备名额；即使联不上许可服务，本机数据也会照常清除。

## 购买与订单

在官网购买许可时，购买页会把购买邮箱、售卖项、支付方式、交易单号与人机验证令牌发送给译无界的许可服务，用于人工审核与发放许可。订单数据不用于营销，也不会进入扩展。

购买页会加载 Cloudflare Turnstile 完成人机验证。它是本站唯一的第三方脚本，只在销售开启时加载；销售关闭时，购买页不加载 Turnstile，也不向许可服务发送请求。

## 本站官网

购买页以外的页面不使用 Cookie，不加载第三方统计或广告脚本，也不收集访问数据。页面只从本站加载字体、脚本与样式，不请求外部 CDN；购买页在销售开启时会加载 Cloudflare Turnstile 人机验证。站内搜索索引随站点一起发布。

官网上的机器翻译申请指南会链接到 Google、Microsoft、阿里云与火山引擎的网站；这些网站的隐私政策由各自厂商负责。

## 变更与联系

功能或数据流发生变化时，本页会同步更新。对隐私有疑问或发现问题，请到 [GitHub 反馈仓库](https://github.com/beyond-translate/feedback/issues) 提出。
