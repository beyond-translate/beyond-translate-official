Beyond Translate 的「机器翻译」选项卡可以使用阿里云机器翻译（通用版）官方接口。它走你自己的阿里云账号，不受免费端点限流的影响，用量与费用也记在你的账号上。

## 免费额度与计费

- 通用版每月有 **100 万字符** 免费额度，主账号与子账号共享，月初清零、不累计。
- 超出免费额度后按量后付费（目前为 50 元 / 百万字符）。额度用完会立刻转为后付费，账户欠费后服务立即停止。**请记得查看额度，避免产生意外费用。**
- 整页翻译消耗的字符数与页面文字量成正比，长页面和反复重译会累积用量。
- 以上数据查看于 2026-11-06，最新数字以 [官方计费说明](https://help.aliyun.com/zh/machine-translation/product-overview/billing-overview) 为准。
- 扩展默认最多同时发 5 个请求，遇到限流会自动放慢。

## 申请步骤

1. 登录 [阿里云](https://www.aliyun.com/)，完成实名认证。
2. 打开 [机器翻译控制台](https://mt.console.aliyun.com/)，开通 **通用版** 机器翻译（未开通时调用会报「账号未开通」）。
3. 建议创建 **RAM 子账号** 专门给扩展用，不要使用主账号的 AccessKey（见下文）。
4. 为子账号创建 AccessKey：在 [RAM 控制台](https://ram.console.aliyun.com/users) 进入该用户，点 **创建 AccessKey**，复制 **AccessKey ID** 与 **AccessKey Secret**。Secret 只在创建时显示一次，请立即保存。

申请完成后，建议把凭据存进[安全笔记](../#安全笔记)。

## 使用子账号并只授予机器翻译权限

AccessKey 是长期凭据，泄露后他人可以盗用你的额度。用子账号并只授予机器翻译权限，可以把影响降到最小：

1. 在 RAM 控制台新建用户，勾选 **使用永久 AccessKey 访问**。
2. 在 **权限管理 → 新增授权** 里，直接为该用户授予系统策略 **`AliyunMTReadOnlyAccess`**（包含 `alimt:Get*` 与 `alimt:List*`，即可调用批量翻译接口 `GetBatchTranslate`）；或者创建并授予最小自定义策略：

   ```json
   {
     "Version": "1",
     "Statement": [
       {
         "Effect": "Allow",
         "Action": ["alimt:GetBatchTranslate", "alimt:TranslateGeneral"],
         "Resource": "*"
       }
     ]
   }
   ```

3. 不要给该用户其他权限。

## 在扩展里使用

1. 打开扩展设置页，进入「翻译服务」分区的「机器翻译」选项卡。
2. 在阿里云机器翻译一行点 **配置**，填入 AccessKey ID 与 AccessKey Secret，点 **测试**。测试只翻译一个单词，消耗几个字符的额度。
3. 测试通过后，它会出现在默认、划词、整页的翻译服务选择器里；清空任一字段后它会从选择器里消失，已选它的槽位回到默认规则。

AccessKey 保存在扩展配置里，随加密备份与同步一起走，不会出现在日志或错误信息里。

## 常见错误

| 提示                   | 原因与处理                                                               |
| ---------------------- | ------------------------------------------------------------------------ |
| AccessKey 被拒绝       | ID 或 Secret 填错；账号未开通机器翻译；子账号没有上面的权限策略。        |
| 请求签名已过期         | 本机时间偏差超过约 15 分钟；校准系统日期和时间后重试。                   |
| 额度用尽或请求过于频繁 | 免费额度已用完，或请求太频繁；稍后再试，或到阿里云控制台查看额度与账单。 |
| 不支持该目标语言       | 阿里云不支持该语言；换一种目标语言，或改用其他翻译服务。                 |
