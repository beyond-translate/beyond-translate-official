Beyond Translate 的「机器翻译」选项卡可以使用 Azure Translator（文本翻译 v3）官方接口。它走你自己的 Azure 账号，不受免费端点限流的影响，用量与费用也记在你的账号上。

## 免费额度与计费

- 提供 **免费层（Free F0）** 定价，每月享有 **200 万字符（2,000,000 字符）** 免费额度，月初清零、不累计。
- **F0 免费层的防扣费机制**：当月 200 万字符用尽后，接口会直接返回 403 / 429 报错停止响应，**不会自动转为付费计费，无扣费风险**。如需更高用量才需升级为 S1 付费层（目前为 10 美元 / 百万字符）。
- **Azure 订阅与扣费说明**：创建 Translator 资源必须依托一个 Azure 订阅（Subscription）。新账号可申请 **Azure 免费试用版（Free Trial）**：
  - 免费试用订阅默认开启 **0 美元支出限制（Spending Limit = 0）**。
  - 试用期赠送 200 美元赠金（有效期 30 天）。赠金耗尽或 30 天试用期结束后，所有需付费资源会自动挂起，**绝不会自动向绑定的信用卡扣费**（除非在控制台中主动升级为随用随付）。
  - Translator F0 属于 Azure 提供的永久免费服务，在试用期结束后依然可以长期免费使用。
- 整页翻译消耗的字符数与页面文字量成正比，长页面和反复重译会累积用量。
- 以上数据查看于 2026-11-07，最新数字以 [官方定价页](https://azure.microsoft.com/pricing/details/cognitive-services/translator/) 为准。
- 扩展默认最多同时发 10 个请求，遇到限流会自动放慢。

## 申请步骤

1. 登录 [Azure 门户](https://portal.azure.com/)。
2. 确认拥有有效订阅：若当前账号无任何订阅，可在门户主页点击「从 Azure 免费试用版开始」，按照指引验证手机号并绑定一张信用卡完成免费试用订阅申请（信用卡仅做真实身份验证，免费期内不扣费）。
3. 在门户顶部搜索栏输入 **翻译工具** 或 **Translator**（在「市场」或「Azure AI 服务」分类下），点击 **创建**。
4. 填写基本配置信息：
   - **订阅（Subscription）**：选择有效订阅（例如 `Azure subscription 1`）。
   - **资源组（Resource Group）**：点击「新建」或选择现有资源组（例如 `rg-translator`）。
   - **区域（Region）**：建议选择 `East Asia`（东亚，香港机房，网络延迟较低）或其他地理区域。**注意**：新建资源组时不可选「全球（Global）」，因为新建资源组需要明确的物理位置。
   - **名称（Name）**：填写全局唯一的英文字符名称（例如 `beyond-translator-test`）。
   - **定价层（Pricing tier）**：**务必选择 `Free F0 (Up to 2M characters translated per month)`**。
5. 点击底部的 **审阅并创建（Review + create）**，等待系统最终验证通过后点击 **创建**。部署通常在 10 到 30 秒内完成。
6. 部署完成后进入该翻译器资源详情页，在左侧菜单的「资源管理」分组中点击 **密钥和终结点（Keys and Endpoint）**。
7. 复制 **密钥 1**（Key 1 或 Key 2 均可），以及同一页上的 **位置/区域（Location/Region）**（例如 `eastasia`）。

申请完成后，建议把凭据存进[安全笔记](../#安全笔记)。

## 区域怎么填

填「密钥和终结点」页上的 **位置/区域** 值，小写、不带空格，例如 `eastasia`、`westus2`、`japaneast`。如果资源创建在 Global 区域，就填 `global`。区域必须是该 Key 实际部署的区域代码，否则 Azure 会以 401 未授权拒绝请求。

## 在扩展里使用

1. 打开扩展设置页，进入「翻译服务」分区的「机器翻译」选项卡。
2. 在 Azure Translator 一行点 **配置**，粘贴 Key、填写区域，点 **测试**。测试只翻译一个单词，消耗几个字符的额度。
3. 测试通过后，它会出现在默认、划词、整页的翻译服务选择器里；清空 Key 后它会从选择器里消失，已选它的槽位回到默认规则。

Key 与区域保存在扩展配置里，随加密备份与同步一起走，不会出现在日志或错误信息里。

## 设置费用提醒（付费层）

如果未来将资源升级为 S1 付费层，可在 **成本管理 + 计费 → 预算** 新建预算，设一个你能接受的月度金额与提醒阈值。预算提醒只发通知，不会自动停用服务；使用 Free F0 免费层时不会产生任何费用。

## 常见错误

| 提示                            | 原因与处理                                                              |
| ------------------------------- | ----------------------------------------------------------------------- |
| Key 被拒绝，或区域与 Key 不一致 | Key 复制不完整，或区域与资源的不一致；回到第 7 步重新复制两项。         |
| 额度用尽或请求过于频繁          | 免费层本月 200 万字符已用完，或请求太频繁；稍后再试，或改用 S1 付费层。 |
