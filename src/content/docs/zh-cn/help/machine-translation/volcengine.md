Beyond Translate 的「机器翻译」选项卡可以使用火山引擎机器翻译官方接口。它走你自己的火山引擎账号，不受免费端点限流的影响，用量与费用也记在你的账号上。

## 免费额度与计费

- 每月前 **200 万字符** 免费，按日结算；超出后按量后付费（目前为 49 元 / 百万字符，暂无阶梯价）。
- 仅支持后付费：余额为负后最晚次日中午停服，欠费期间不保证可用。**请记得查看用量，避免产生意外费用。**
- 整页翻译消耗的字符数与页面文字量成正比，长页面和反复重译会累积用量。
- 以上数据查看于 2026-11-06，最新数字以 [官方计费说明](https://docs.volcengine.com/docs/MachineTranslation/Productbilling?lang=zh) 为准。
- 扩展默认最多同时发 5 个请求，遇到限流会自动放慢。

## 申请步骤

1. 登录 [火山引擎](https://www.volcengine.com/)，完成实名认证。
2. 打开 [机器翻译控制台](https://console.volcengine.com/translate)，开通机器翻译服务。
3. 建议创建 **IAM 子用户** 专门给扩展用，不要使用主账号的密钥（见下文）。
4. 为子用户新建密钥：在 **身份管理 → 用户** 里进入该用户，选 **密钥 → 新建密钥**，复制 **Access Key ID** 与 **Secret Access Key**。Secret 只在创建时显示一次，请立即保存。

申请完成后，建议把凭据存进[安全笔记](../#安全笔记)。

## 使用子账号并只授予机器翻译权限

密钥是长期凭据，泄露后他人可以盗用你的额度。用子用户并只授予机器翻译权限，可以把影响降到最小：

1. 在 **身份管理 → 用户** 新建用户，勾选 **编程访问**。
2. 在权限设置里只添加机器翻译的系统策略 **TranslateFullAccess**（可在用户的 **权限 → 添加权限** 里搜索）。
3. 不要给该用户其他权限。

## 在扩展里使用

1. 打开扩展设置页，进入「翻译服务」分区的「机器翻译」选项卡。
2. 在火山引擎机器翻译一行点 **配置**，填入 Access Key ID 与 Secret Access Key，点 **测试**。测试只翻译一个单词，消耗几个字符的额度。
3. 测试通过后，它会出现在默认、划词、整页的翻译服务选择器里；清空任一字段后它会从选择器里消失，已选它的槽位回到默认规则。

密钥保存在扩展配置里，随加密备份与同步一起走，不会出现在日志或错误信息里。地域固定为华北区（cn-north-1），无需填写。

## 常见错误

| 提示                   | 原因与处理                                                              |
| ---------------------- | ----------------------------------------------------------------------- |
| Access Key 被拒绝      | ID 或 Secret 填错；账号未开通机器翻译；子用户没有 TranslateFullAccess。 |
| 请求签名已过期         | 本机时间偏差较大；校准系统日期和时间后重试。                            |
| 额度用尽或请求过于频繁 | 免费额度已用完，或请求太频繁；稍后再试，或到火山引擎控制台查看用量。    |
| 不支持该目标语言       | 火山引擎不支持把文字译成该语言；换一种目标语言，或改用其他翻译服务。    |
