## 必须自己准备 API Key 吗？

不必须。不做任何配置也能使用内置的 Google 翻译与 Bing 翻译免费端点。中文界面默认用 Bing 翻译，其余界面默认用 Google 翻译；添加第一个模型条目后，默认服务会改为该模型。

想用更好的模型或云厂商官方机器翻译时，再按 [机器翻译服务](machine-translation/) 的指南申请并填入自己的凭据。

## 支持哪些浏览器？

Chromium 系（Chrome 111+、Edge）与 Firefox 136+，使用 Manifest V3。

## 翻译会把我的网页内容上传吗？

只会把需要翻译的文字发给你在扩展里选择的翻译服务：

- 使用免费端点时，文字发给 Google 或 Microsoft。
- 使用 Google Cloud、Azure、阿里云或火山引擎官方 API 时，文字发往你自己的云账号。
- 开启兜底翻译后，模型仍失败的整页段落会再发给所选的兜底机器翻译服务。

扩展不记录来源页面，不做后台统计，也没有广告。Firefox 安装时的数据外发声明对应该行为。

## API Key 和同步凭据存在哪里？

API Key、云厂商 Access Key、网盘授权、GitHub 令牌与 WebDAV 密码只保存在本机的扩展存储中。内容脚本拿不到这些凭据；它们会随加密备份与同步一起走，但不会出现在日志或错误信息里。

## 备份和同步安全吗？

备份与同步文件始终用数据密钥加密。备份可以导出为 `.zip`，也可以通过 Gist 或 Dropbox、Google Drive、OneDrive、WebDAV 手动上传与下载；上传、下载、历史与恢复都在用户手动操作时进行，不会自动触发。

## 有付费功能吗？

划词翻译、整页翻译、生词本、译文存档等基础功能免费。备份还原与站点规则的写入需要一次性买断许可，不会自动续费。许可在[购买页](../../buy/)出售，随扩展上架开售；许可绑定购买邮箱，最多允许 5 台设备同时激活，不会过期，可以随时停用设备腾出名额。未激活的许可可联系支持邮箱退款，已激活的许可不支持退款。

许可状态只存本机，不进入备份与同步；在扩展设置页的「许可」分区用购买邮箱激活。

## 如何购买许可？

1. 在[购买页](../../buy/)选择支付方式，按页面显示的金额付款。收款码不含金额时，需要手动输入页面显示的金额；USDT 只能在页面写明的网络上转账，转错网络会丢失资金。
2. 付款后回到购买页，填写购买邮箱、支付方式与交易单号，并完成人机验证。交易单号是 6–66 位字母、数字、下划线或连字符，各支付方式的单号位置见页面提示。
3. 等待人工审核。审核通过后，你会收到「许可已就绪」邮件；同一笔付款只需提交一次。
4. 在扩展的「许可」分区用购买邮箱获取验证码并激活，激活邮箱必须与购买邮箱一致。

价格、可用的支付方式、人工审核时间与支持邮箱以购买页为准；开售前，购买页只显示开售说明。

## 能离线使用吗？

不能。翻译需要调用所选的翻译服务；没有网络时，已经缓存或已存入译文存档的内容仍可显示。

## 翻译会保存吗？

翻译缓存只存在本机，用于复用已成功的译文，不入备份、不同步。译文存档是可选功能：手动存入或按站点规则自动存档后，再打开同一页可以直接上屏，不必重新请求翻译服务。

## 官网收集访问数据吗？

不。购买页以外的页面不使用 Cookie、不加载第三方统计脚本，也不收集访问数据。销售开启时，购买页会加载 Cloudflare Turnstile 完成人机验证。扩展本身的隐私边界见 [隐私说明](privacy/)。
