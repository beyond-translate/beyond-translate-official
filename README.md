# 译无界官网

译无界（Beyond Translate）划词与整页翻译：隐私优先、不追踪、成本可控、译文存档复用、界面精致，遥遥领先。

站点包含：

- 首页：产品介绍、功能、两种整页模式、翻译引擎、隐私承诺、上架状态与常见问题。
- 帮助中心：快速上手、机器翻译服务概览，以及 Google Cloud、Azure、阿里云、火山引擎的申请指南。
- 购买页：一次性许可的受控购买页；销售关闭时只显示开售说明。
- 隐私说明：密钥、网页文字、缓存、备份、购买与许可分别去了哪里。

扩展已在 Chrome、Edge 与 Firefox 上架：

- Chrome：[Chrome Web Store](https://chromewebstore.google.com/detail/beyond-translate/ihimgeclocmlahdijnakgcglfcijinej)
- Edge：[Microsoft Edge 加载项](https://microsoftedge.microsoft.com/addons/detail/beyond-translate/naeehdedaeachnpmfjgblghmfgnkedbh)
- Firefox：[Firefox 附加组件](https://addons.mozilla.org/firefox/addon/beyond-translate/)

问题与建议请提交到 [反馈仓库](https://github.com/beyond-translate/feedback/issues)。
